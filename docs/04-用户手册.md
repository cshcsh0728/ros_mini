## 1 这是什么

这是一个用 C++17 写的「迷你 ROS」：在一个程序内部模拟机器人系统中的发布/订阅通信。

你可以创建若干个**发布者**（向某个话题发消息）和**订阅者**（从某个话题收消息），
中间由核心模块负责按话题转发。它不连接真实 ROS，也不需要安装任何机器人软件，
编译即可运行。

**适合用来**：理解 ROS 的节点/话题概念、练习 C++ 面向对象与异常处理。
**不适合用来**：替代真实 ROS 做跨进程通信。

## 4 编译

### 方式一：Visual Studio（图形界面，推荐）

1. 打开 Visual Studio
2. 菜单 **文件 → 打开 → 文件夹**，选择 `ros_mini` 文件夹
3. 等待右下角提示 CMake 配置完成（首次约 10~30 秒）
4. 顶部工具栏的**启动项下拉框**选择 `rosmini_demo.exe`
5. 按 **F5** 运行

> 如果启动项下拉框是空的：按 F5，会弹「选择启动项」对话框，选 `rosmini_demo.exe` 即可。

### 方式二：命令行

```bash
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build
```

生成的可执行文件：

- `build\rosmini_demo.exe`（Windows）或 `build/rosmini_demo`
- `build\rosmini_tests.exe`（Windows）或 `build/rosmini_tests`

## 7 查看日志文件

程序启动时会调用 `Logger::setLogFile("rosmini.log")`，日志会**同时**输出到控制台和该文件。

- 文件位置：**程序当前工作目录**（VS 里运行一般在 `out\build\x64-Debug\`；命令行运行在当前目录）
- 编码：UTF-8
- 追加写入：多次运行不会覆盖

用 VS 或记事本打开即可；若用记事本打开出现乱码，请选择「UTF-8」编码。

## 8 自己搭一个场景

核心库已被编译成 `rosmini_core`，新建一个 `.cpp` 并链接它即可。

```cpp
#include "rosmini/Publisher.h"
#include "rosmini/Subscriber.h"
#include "rosmini/ROS.h"
#include "rosmini/Logger.h"

int main() {
    rosmini::Logger::setMinLevel(rosmini::LogLevel::Info);

    rosmini::Publisher  pub("my_pub", "my_topic");
    rosmini::Subscriber sub("my_sub", "my_topic");

    pub.init();          // 向核心注册并输出初始化日志
    sub.init();

    pub.publish("hello, rosmini");   // 订阅者会打印接收日志
    pub.publish("second message");

    rosmini::ROS::instance().shutdownAll();   // 统一关闭全部节点
    return 0;
}
```

编译时在 `CMakeLists.txt` 里加：

```cmake
add_executable(my_demo my_demo.cpp)
target_link_libraries(my_demo PRIVATE rosmini_core)
```

### 想新增一种节点类型？

1. 新建 `MyNode.h` / `MyNode.cpp`，`class MyNode : public rosmini::Node`
2. 实现 `init()` 与 `shutdown()`（记得打日志）
3. 在 `init()` 里调用 `rosmini::ROS::instance()` 的注册接口
4. **不需要**修改核心模块 —— 这正是「面向抽象编程」的好处

## 9 常见问题

### Q1：控制台中文是乱码

程序已经在 `main` 里调用 `SetConsoleOutputCP(CP_UTF8)`。若仍乱码，通常是**终端字体**问题：
右键控制台标题 → 属性 → 字体，选 `Consolas` 或 `Microsoft YaHei`。
用 VS 的「输出」窗口看日志时也建议切换字体。

### Q2：按 F5 报「无法启动程序 … 系统找不到指定的文件」

说明启动项没选对或还没编译成功。检查顶部下拉框是否为 `rosmini_demo.exe`；
若是空的，先按 `Ctrl+Shift+B` 生成一次。

### Q3：VS 里 `#include "rosmini/xxx.h"` 被标红，但能编译

IntelliSense 缓存过期。菜单 **项目 → 删除缓存并重新配置**，或关闭文件夹重新打开。

### Q4：CMake 报 `Cannot find source file`

`CMakeLists.txt` 里列出的某个源文件不存在。检查文件是否被误删或改名，
必要时手动执行「删除缓存并重新配置」。

### Q5：运行后没有生成 `rosmini.log`

检查程序运行时的工作目录是否可写。VS 调试运行时目录是 `out\build\x64-Debug\`，
在该目录下找找看。

### Q6：多个发布者发到同一话题，会不会互相覆盖？

不会。核心模块用「话题 → 列表」保存节点，同一话题允许多个发布者与多个订阅者，
每个订阅者都会收到该话题上的**每一条**消息。

## 10 卸载与清理

本项目不写注册表、不装服务，删除整个文件夹即可。

若只想清理编译产物：删除 `build/`（或 `out/`）目录与 `rosmini.log` 即可，
源码与文档不受影响。
